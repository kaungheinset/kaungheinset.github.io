PROJECT 04 / ETHICAL HACKING / LAB ASSESSMENT

Understand the weakness. Prove the impact.

Assessing deliberately vulnerable hosts, enumerating services, and validating security weaknesses in explicitly authorized lab environments.

01 / CONTEXT

Project overview

Offensive security exercises help me understand the attacker behaviors that security teams must detect. My labs include service discovery, misconfiguration analysis, authenticated access validation, and host-level privilege-escalation investigation.

Every test described here took place in a permitted training environment. The goal is a reproducible technical finding, not an attack against a real organization.

02 / WORKFLOW

My approach

  • Discovery: enumerated exposed SSH, SMB, Apache, and Tomcat services on vulnerable Linux lab targets.
  • Validation: assessed anonymous SMB enumeration and weak authentication paths in a practice environment.
  • Host investigation: reviewed exposed keys and local misconfigurations, including passphrase-protected key analysis with John the Ripper.
  • Post-exploitation learning: used Metasploit and privilege-enumeration tools in a separate intentionally vulnerable training exercise.

03 / OBSERVATIONS

Selected findings

01

Attack-surface mapping

Mapped the host services and identified where misconfigurations or weak credentials created exploitable conditions in the lab.

02

Credentials and key exposure

Followed a lab scenario involving an exposed SSH private key and passphrase recovery to understand credential-risk impact.

03

Evidence-driven reporting

Documented each observed finding and considered the defensive telemetry that would help a SOC identify similar activity.

04 / NEXT ITERATION

What comes next

Continue preparing for the INE eJPT exam. Add concise vulnerability reports and remediation recommendations to future authorized lab write-ups. Exam preparation is in progress; eJPT is not yet a completed certification.
